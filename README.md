# Hardware Review Templates

## Purpose

This repository provides templates for conducting independent hardware reviews and documenting sample request outreach to manufacturers. The goal is to maintain an honest, transparent, and technically rigorous approach to hardware evaluation.

## Templates

This repository contains templates for:

- **Video review outlines**: Structured frameworks for producing honest, informative hardware review videos.
- **Sample request emails**: Templates for reaching out to manufacturers to request review samples.

## Important Statement

This repository contains **templates only**. There are **no completed product reviews** hosted here, and **no manufacturer partnerships or paid review arrangements** are claimed. All future reviews conducted using these templates will be independent, and any sponsored or partnered work will be clearly disclosed.
